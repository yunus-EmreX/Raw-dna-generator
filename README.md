Simulated RAW DNA Generator (Demo)
Bu proje, analiz sitelerinin kabul ettiği “rsid / chromosome / position / genotype” formatında tamamen sentetik RAW DNA (.txt) dosyası üretmek için hazırlanmış tek sayfalık bir HTML uygulamasıdır. Gerçek genetik veri içermez.

Özellikler
İstenen satır sayısında çıktı üretimi (1.000–300.000 arası)

Seed ile deterministik (aynı seed + satır sayısı = aynı dosya)

Sadece otozomlar (1–22) veya 1–22 + X/Y/MT seçenekleri

İndirilebilir .txt dosyası

Önizleme ilk satırlar

Dosya Yapısı
rawdnagenerator.html.html: Tüm HTML/CSS/JS içeren tek sayfa uygulama

Kullanım
rawdnagenerator.html.html dosyasını tarayıcıda açın.

“Satır sayısı” ve “Seed” değerlerini ayarlayın.

“Kapsam” ve “Dosya adı” seçin.

“Dosyayı üret ve indir” butonuna tıklayın.

Tarayıcı, oluşturulan dosyayı otomatik olarak indirir.


Üretilen veri tamamen sentetiktir ve sadece demo/format testi amaçlıdır.

100.000+ satır üretimi tarayıcıda kısa süreli donmalara neden olabilir.
